# One Star, Five Stars for the Food

A one-sentence, one-star review of Earth by an alien tourist that still praises the food — entry for the [make.fun bounty](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7).

The entry:

> One star for Earth, where the locals can't photosynthesise, pay for water, and invented Mondays — but the dumplings are the best thing my tentacles have ever tasted.

`main.py` (Python, standard library only) writes that exact sentence to `/output/entry.txt`, deterministically.

## How to run

```
python3 main.py
```

This writes the review to `/output/entry.txt` (created if needed). Running it twice produces byte-identical output.
